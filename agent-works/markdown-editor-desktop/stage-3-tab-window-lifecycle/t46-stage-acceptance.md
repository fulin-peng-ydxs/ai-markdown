## 4. 整体审查

### 4.1 代码与数据安全

- Rust 平台路径身份是页签唯一性的权威；分隔符、相对段和 Windows 大小写别名不由前端猜测。
- 不可复用 incarnation 与 generation/editVersion 阻止关闭重开 ABA、慢读取和陈旧重映射污染。
- 关闭和文件操作使用不可变结算证据；继续编辑会使证据失效并要求重新处理。
- Markdown 始终由用户工作区真实文件与内存 `DocumentSession` 承载；窗口会话仓储不保存正文/history。
- 会话 session/manifest 崩溃中间态可前滚；未知 schema 不覆盖，损坏与单项失败隔离。
- 磁盘操作成功前不更新正式页签、树或链接；失败不展示虚假成功。

### 4.2 业务闭环

- 打开同一路径聚焦既有页签；关闭最后页签保留绑定工作区的空窗口，关闭窗口使用独立命令。
- 单项/其他/右侧/全部关闭以及文件操作、窗口替换/关闭/退出复用同一结算链，没有第二套保存或冲突通道。
- `ask/current_window/new_window` 可保存、读取、消费并恢复为 `ask`；同目录去重和内容安全门禁优先于偏好。
- 会话恢复失败按项隔离，致命输入降级后仍解冻后续安全会话写入。
- 移动资源目录或含受支持图片的目录继续采用已确认的可能断链提示，不虚构跨文档引用命中。

### 4.3 页面、复用与 DESIGN

- `WorkspaceTabBar`、共享 `TabMenu`、`TabSettlementDialog`、两个工作区打开弹层、`WorkspaceTabManager`、会话持久化和路径影响分析均已登记并被真实消费者使用。
- 弹层复用 `AppDialog`、`AsyncStatePanel` 和内容安全摘要；上下文/溢出菜单复用同一菜单基元；未发现重复组件、第二套路径代数或第二套状态优先级。
- tablist、`aria-selected`、roving tabindex、明确关闭名称、菜单方向键/Esc/焦点返回、非颜色状态和 reduced-motion 已覆盖。
- 阶段 3 CSS 消费语义 token；没有新增私有颜色体系、营销卡片或与 P1 主任务无关的装饰。
- 本次 T46 不修改页面，因此没有新增截图；页面证据沿用 T45 双平台真实桌面 E2E 与此前视口/原型复核。

### 4.4 数据库、配置、权限、菜单与环境

- 无数据库、SQL 或 seed，不需要新增或迁移。
- 无新增产品环境变量；E2E 环境只存在于 feature-gated 隔离构建。
- 新增持久化均为应用数据目录中的版本化 JSON，并具有容量、校验、原子替换、损坏回退和旧版本安全退化。
- capability 未扩张到任意绝对路径、shell 或仓库外访问；Rust 继续重校验授权根、窗口绑定和相对路径。
- 原生菜单按聚焦窗口真实状态启用；macOS 原生加速键和 Windows WebView 平台按键适配只进入同一命令处理器，避免双分发。

## 实现与安全边界

- 前端命令只接受 workspaceId、相对路径、目标目录和名称；Rust 从工作区登记表取得 canonical root，并在临近 I/O 时复核根类型、相对路径、现有节点和符号链接。
- 新建 Markdown 名称没有扩展名时补 `.md`，其他扩展名拒绝；目录名称原样保留。名称拒绝空值、首尾空白、控制符、路径分隔符、`<>:"|?*`、结尾点号、Windows 保留名、超过 255 bytes/UTF-16 单元及点号隐藏项。点号项当前被拒绝，是因为第一阶段 `showHidden=false` 且尚无设置入口，避免操作成功后节点立即从树中消失。
- 新文件使用 `create_new` 且同步后才提交；同步或提交元数据失败会删除未提交空文件。新目录使用单级 `create_dir`，不隐式创建未知父目录。
- 服务内串行化消除同进程并发重名；macOS `renamex_np(RENAME_EXCL)` 与 Windows 不带 replace 的 `MoveFileExW` 负责平台原子无覆盖。目标存在、跨设备、同位置及目录移动到自身/后代分别返回稳定错误。
- Rust 成功结果包含真实新 `FsEntry` 和旧路径。前端 mutation reducer 在 processing 时不乐观修改树；成功后新增或重映射整个子树并失效相关 scanId，失败只保存错误，原路径、子项和选中依据保持不变。
